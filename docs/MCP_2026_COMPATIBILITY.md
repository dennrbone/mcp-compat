# Профиль инструментов MCP 2026-07-28

Схемы протокола и исходный файл лицензии сохранены в
`protocol/mcp-2026-07-28`. Версия, исходный коммит и контрольные суммы
приведены в `provenance.json`.
[Спецификация MCP](https://modelcontextprotocol.io/specification/2026-07-28).

## Окружения

| SDK | Зависимости | Код |
|---|---|---|
| `mcp==1.30.0` | `requirements.lock` | `src/mcp_compat/mcp_integration.py` |
| `mcp==2.3.0` | `requirements-mcp2026.lock` | `examples/mcp2026_server.py` |

SDK устанавливаются в отдельных окружениях. Для экспериментов статьи
используется SDK 1.30.0. Профиль SDK 2.3.0 проверяется отдельными тестами.

## Что проверяют тесты SDK 2.3.0

- Запросы `tools/list` и `tools/call` выполняются без предварительного
  `initialize` в профиле 2026-07-28. Сообщения проверяются по сохранённой
  схеме протокола.
- Проверяется метаинформация запросов. Сообщения без обязательных данных
  и с неизвестной версией протокола отклоняются.
- Проверяются входная и выходная схемы, структурированные ответы в виде
  объекта или массива, неизвестное имя инструмента и ошибки обработчика.
- Отдельный тест проверяет соединение старого клиента с новым сервером и
  нового клиента со старым сервером через стандартный ввод и вывод.
- `make_proxy_2026` принимает `admission` и `current_state` вместе. Если
  они заданы, перед отправкой вызова связанному серверу прокси проверяет
  свидетельство и актуальность снимка.

Испытан профиль вызова инструментов через стандартный ввод и вывод
и транспорт в памяти. Проверки Streamable HTTP, авторизации, подписок
и расширений выходят за его пределы.

Анализ изменений контракта и проверка формы вызова выполняются отдельно.
`strict` отклоняет неполное сравнение. `compat` продолжает проверку для
поддерживаемых различий с `EvidenceVerifier` и функцией чтения снимка.
Условия допуска описаны в [описании проверки](METHOD_FORMALIZATION.md).

## Локальный запуск

```sh
python3.11 -m venv /tmp/mcp2026
/tmp/mcp2026/bin/python -m pip install --upgrade pip
/tmp/mcp2026/bin/python -m pip install --require-hashes -r requirements-mcp2026.lock
/tmp/mcp2026/bin/python -m pip install --no-deps -e .
MCP_COMPAT_LEGACY_PYTHON="$PWD/.venv/bin/python" /tmp/mcp2026/bin/python -m pytest -q tests/mcp2026
```

`MCP_COMPAT_LEGACY_PYTHON` указывает на Python с SDK 1.30.0. Без него
двусторонняя проверка версий пропускается. Пример для клиента SDK 2.3.0
запускается командой `/tmp/mcp2026/bin/python examples/mcp2026_server.py`
и публикует инструмент `echo`.

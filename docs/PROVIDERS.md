# Подключение модели к Hybrid

В обоих режимах Hybrid сначала ищет решение по контрактам и встроенным
правилам. Если поиск не дал подходящего кандидата, алгоритм может обратиться
к `Mapper`. Модель получает контракты и прежний вызов и возвращает операции
над аргументами либо отказ. Решение о допуске принимает Hybrid после
проверки схемы, ответа и состояния.

- **GigaCode CodeAgent** использует локальный клиент с идентификатором
  `gigacode/GigaCode`. Укажите абсолютный путь к нему в `GIGACODE_BIN`.
- **GPT‑6.1 Terra** использует авторизованный `codex` из `PATH` с
  идентификатором `gpt-6.1-terra`.

В обоих случаях используется авторизация, настроенная в установленном
клиенте. Один флаг выбирает модель, другой — режим Hybrid.

```sh
.venv/bin/python examples/hybrid_study.py --dataset external \
  --provider codeagent --hybrid-mode compat \
  --output experiments/hybrid/external-compat-codeagent
```

С заменой `--provider terra` тот же алгоритм получает доступ к Terra.
Значения `--hybrid-mode strict` и `--hybrid-mode compat` задают условия,
при которых Hybrid начинает проверку. Подготовка серверов и полный
порядок запуска описаны в [инструкции воспроизведения](REPRODUCIBILITY.md).

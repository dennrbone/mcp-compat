# Прогон Hybrid с подключёнными моделями

CodeAgent и GPT‑6.1 Terra подключались к Hybrid через `Mapper`.
Модель вызывается, когда анализ контрактов разрешил поиск, а встроенные
правила и проба прежних аргументов не дали подходящего кандидата.

«Случаи / запросы» показывает число сценариев с обращением к модели и
число запросов. «Повторы» считает запросы после первого в каждом сценарии.
«Допуски после LLM» учитывает допущенные вызовы по операциям модели.
«Ложные допуски» показывает расхождения ответа или состояния среди
допущенных вызовов. В колонке «Успешно» для основного набора учитываются
подтверждённые вызовы среди сценариев с разметкой «восстановим». Для
исторического набора учитываются подтверждённые вызовы среди всех сценариев.

## Основной набор из 208 сценариев

В набор вошли 200 сценариев на закреплённых версиях Filesystem, SQLite
и Calculator и восемь синтетических проверок `propertyNames` и
`patternProperties`. В разметке 85 случаев отмечены как восстановимые.

| Режим | Модель | Случаи / запросы | Повторы | Успешно | Допуски после LLM | Ложные допуски |
|---|---|---:|---:|---:|---:|---:|
| strict | GigaCode CodeAgent | 77 / 153 | 76 | 57/85 | 0 | 0/58 |
| strict | GPT‑6.1 Terra | 77 / 77 | 0 | 81/85 | 24 | 0/82 |
| compat | GigaCode CodeAgent | 83 / 164 | 81 | 59/85 | 0 | 0/60 |
| compat | GPT‑6.1 Terra | 83 / 83 | 0 | 85/85 | 26 | 0/86 |

На синтетических проверках ключей `compat` подтвердил два вызова с прежними
аргументами. Terra помогла восстановить ещё два вызова. Все четыре
отрицательных сценария были отклонены.

В каждой конфигурации дополнительно прошёл сценарий `calculator-53-lossy`,
помеченный в эталоне как невосстановимый. Усечение односимвольного ответа
оставило его прежним, и независимая проверка подтвердила совпадение ответа
и состояния. Этот вызов учитывается в знаменателе «Ложных допусков».

## Исторический набор из 29 сценариев

Набор объединяет 14 изменений схем Filesystem, 9 изменений Memory
и 6 проверок на Firecrawl 3.24.0 и 3.25.0 и двух опубликованных снимках
Random User MCP.

| Режим | Модель | Случаи / запросы | Повторы | Успешно | Допуски после LLM | Ложные допуски |
|---|---|---:|---:|---:|---:|---:|
| strict | GigaCode CodeAgent | 6 / 12 | 6 | 17/29 | 0 | 0/17 |
| strict | GPT‑6.1 Terra | 6 / 6 | 0 | 17/29 | 0 | 0/17 |
| compat | GigaCode CodeAgent | 8 / 16 | 8 | 19/29 | 0 | 0/19 |
| compat | GPT‑6.1 Terra | 8 / 8 | 0 | 19/29 | 0 | 0/19 |

Режим `compat` подтвердил два вызова Random User с допустимыми весами.
Две пробы Firecrawl завершились отказом из-за различия параметра `origin`
при обращении к API.
Ещё два вызова отклонены при проверке входных схем. Ответы внешних API
воспроизводились локальными обработчиками.

Отдельная проверка каталогов DOCX MCP 0.4.0 и 0.5.0 показала добавление
`patternProperties` для сносок. Вложенный `$id` останавливает анализ
до проб в обоих режимах.

## Контроль на других серверах

В отдельном архивном прогоне на девяти вызовах Everything (2025.7.1 и 2.3.1) и
Sequential Thinking (2025.7.1 и 2.2.0) оба режима подтвердили совпадение
ответа и состояния. В отрицательных пробах были отклонены преобразования,
после которых менялась сумма.

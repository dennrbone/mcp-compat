# Прогон Hybrid с подключёнными моделями

CodeAgent и GPT‑6.1 Terra подключались к Hybrid через `Mapper`.
Hybrid обращался к модели после проверки контрактов, если встроенный
поиск ещё не дал подходящего кандидата. На обоих наборах каждый режим
прошёл с обеими моделями.

В колонке «Случаи / запросы» указано число сценариев, где Hybrid обратился
к модели, и общее число запросов. В колонке «Повторы» учтены запросы
после первого в том же сценарии. «Допуски после LLM»
учитывают вызовы, собранные по операциям модели. «Ложные допуски» показывает
число расхождений ответа или состояния из всех допущенных вызовов.
При отсутствии допусков в этой колонке стоит тире. Знаменатель колонки
«Успешно» показывает число восстановимых сценариев по разметке либо
размер исторического набора без такой разметки.

## 200 сценариев и проверка ключей

В наборе восемь случаев, основанных на исторических переименованиях,
четыре контроля сохранения поведения и 188 сконструированных вариантов.
Все сценарии выполняются на закреплённых версиях Filesystem, SQLite
и Calculator с тестовыми данными. В разметке 81 сценарий отмечен как
восстановимый.

В каждой конфигурации был также допущен один вариант, который по
разметке следовало отклонить. Усечение односимвольного ответа оставило
его прежним, а независимое исполнение подтвердило совпадение ответа
и состояния. Этот допуск входит в общий итог, который стоит
в знаменателе последней колонки.

В синтетической группе четыре из восьми вызовов восстановимы.
Terra помогла `compat` перенести значение в поле с новым именем и обернуть
значение в массив. Остальные два успешных вызова прошли с прежними
аргументами. Все четыре отрицательных сценария были отклонены.

В этой группе зарегистрировано шесть ответов Terra. От CodeAgent
ответы не зарегистрированы.

подготовлен вызов к тестовым файлам или графу. При допуске к проверке
стенд выполнял вызовы на обеих версиях через MCP.

В историческом наборе оба режима подтвердили по 17 вызовов с прежними
аргументами. Схемы старых каталогов явно импортировались в обоих режимах.
Дополнительные пробы подтвердили эквивалентный путь, отклонили чтение
другого файла и заблокировали выход за пределы каталога стенда.

В группе из шести вызовов запускали Firecrawl 3.24.0 и 3.25.0 и два
опубликованных снимка Random User MCP. Ответы внешних API задавались
локально. Сравнение включало ответ MCP и отправленные параметры запроса.
`compat` подтвердил оба вызова Random User с допустимыми весами.
Два допустимых по форме вызова Firecrawl изменили параметр `origin` при
обращении к API и были отклонены. Ещё два вызова отклонены по входной схеме.

В каталогах DOCX MCP 0.4.0 и 0.5.0 обнаружено добавление `patternProperties`
для сносок. Вложенный `$id` останавливает анализ в обоих режимах.
В строке «Каталог DOCX» учтена отдельная проверка схемы без исполнения инструмента.

## Контроль на других серверах

На девяти контрольных вызовах Everything (2025.7.1 и 2.3.1) и
Sequential Thinking (2025.7.1 и 2.2.0) оба режима подтвердили совпадение
ответа и состояния. В отрицательных пробах были отклонены преобразования,
после которых менялась сумма.

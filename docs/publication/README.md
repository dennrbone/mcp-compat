- MCP_COMPAT_SCIENTIFIC_REPORT.docx — самостоятельный научно-технический отчёт.
- MCP_COMPAT_ARTICLE_VAK.docx — отдельная статья для авторской проверки и
  последующей адаптации под выбранный журнал ВАК К3, специальность 2.3.5.
- SCIENTIFIC_REPORT.md и ARTICLE.md — научные тексты, из которых собираются DOCX.
- figures/ — рисунки из фактических оценок, PNG высокого разрешения и SVG.
- report-pages.json — проверенные страницы разделов для кеша обновляемого TOC.

## Сборка

Рисунки формируются в окружении научного анализа из requirements.lock:

```sh
MPLCONFIGDIR=/tmp/mcp-plots .venv/bin/python examples/final_publication_figures.py
```

DOCX создаются отдельно, без замены SDK и зависимостей эксперимента:

```sh
uv venv --python 3.12 /tmp/mcp-docx
uv pip sync --python /tmp/mcp-docx/bin/python --require-hashes requirements-publication.lock
/tmp/mcp-docx/bin/python examples/build_publication.py
```

Оформление: A4, Times New Roman 14 pt, основной текст по ширине, интервал 1,5,
отступ первой строки 1,25 см; поля 30/15/20/20 мм. Заголовки имеют native Word
styles и нумерацию; таблицы фиксированную геометрию и повторяемые заголовки.
Формулы представлены редактируемым Office Math, подписи/номера — полями SEQ,
страницы — PAGE. Оглавление содержит TOC/PAGEREF и проверенные кешированные
номера; его можно обновить средствами Word после изменения текста.

Основной текст и оглавление имеют интервал 1,5; невидимая граница поля
TOC имеет минимальный размер и не содержит печатного текста.
Математический шрифт определяется механизмом Office Math. Декоративные линии
и тематические подстановки шрифта заголовков отключены.

## Проверка после изменений

Откройте DOCX в Word либо LibreOffice, обновите поля и оглавление, экспортируйте
временный PDF и проверьте все страницы: формулы, переносы, таблицы, рисунки,
поля, номера и отсутствие пустых страниц. После изменения пагинации обновите
report-pages.json по фактическим страницам и повторите сборку/рендеринг.
Точный вид зависит от установленного Times New Roman и математических шрифтов.

Проверка текущей версии и SHA-256 документов отражены в
`../validation/final-release.json`. Временные PDF и PNG страниц остаются
локальными QA-материалами и не поставляются вместо редактируемых DOCX.

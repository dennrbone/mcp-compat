# Проверенные результаты

## Расширенный набор из 200 сценариев

В наборе восемь случаев, основанных на исторических переименованиях, четыре
контроля сохранения поведения и 188 авторских вариантов. Прогоны на трёх
закреплённых MCP-серверах дали 2 600 решений и 8 852 записи вызовов
инструментов. Оценки пересчитаны по трассам.

| Проверка готовых кандидатов | Корректные допуски | Ложные допуски |
|---|---:|---:|
| Прежняя | 70 | 75 из 130 |
| Строгая | 70 | 0 из 130 |
| Парный вариант без финальной проверки | 70 | 9 из 130 |
| Парный вариант с финальной проверкой | 70 | 0 из 130 |

| Модель | Получено кандидатов из 200 | Восстановлено со строгой проверкой | Семантические ошибки среди строгих допусков |
|---|---:|---:|---:|
| CodeAgent | 175 | 81/81 | 0/82 |
| GPT‑6.1 Terra | 170 | 75/81 | 0/76 |

У CodeAgent запросы повторялись для 55 сценариев после сбоев клиента.
У одного размеченного случая усечение односимвольного ответа сохранило
поведение. Он был допущен и объясняет разницу между числом корректных
восстановлений и общим числом строгих допусков.

## Исторические каталоги

Из восьми установленных выпусков получены 50 изменений входных и выходных
схем существующих инструментов. В 20 случаях одна из опубликованных входных
схем не объявляла тип `object`. Ещё 30 изменений обнаружены анализатором
и содержат неподдерживаемые детали. Десять дополнительных вызовов
Filesystem и Memory подтверждают изменение формата ответов на выбранных
входах.

Проверяются [официальные выпуски MCP Servers](https://github.com/modelcontextprotocol/servers/releases)
и [Playwright MCP](https://github.com/microsoft/playwright-mcp/releases).
Точные версии и контрольные суммы доступны в
[фикстуре каталогов](../tests/fixtures/upstream-catalogs.json).

## Исходный прогон CodeAgent

Проверена целостность 19 440 записей на 2 160 авторских сценариях для
девяти методов. Для 8 357 допусков повторно рассчитано поведение
авторских моделей инструментов. В журналах найдено 11 731 обращение к
клиенту и 10 365 сохранённых ответов, распределённых по 10 320 решениям.
Другие решения включают детерминированные проверки, ранние выходы и
попытки без сохранённого ответа.

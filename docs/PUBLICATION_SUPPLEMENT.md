# Приложение к исследованию mcp-compat

Автор: Россинский Андрей Евгеньевич, Франкфурт, dennrbone@gmail.com.

## Что решает работа

Обновление API может нарушить уже работающий вызов агента. Прототип пытается
перевести этот вызов на новый контракт и проверяет наблюдаемое поведение
перед допуском. Например, при замене `content` на `text` он переносит значение,
проверяет новый запрос и сравнивает результат подсчёта слов двух версий.
Схема, которая принимает JSON, сама по себе не доказывает сохранение смысла.

Готовые достоверные правила предпочтительны в проверенном условии: D1 обошёл
генератор M1. Возможный смысл модели — предложить преобразование, когда готового
правила нет. Это отдельный экспериментальный вопрос; модель не получает права
самостоятельно подтвердить безопасность своего ответа.

Работа не обновляет глобальные настройки агента и не требует привязки ядра к
одному поставщику. Для другого генератора реализуется существующий LLMClient,
для другого MCP-клиента используется стандартное подключение. Реально испытан
GigaCode CodeAgent и отдельная конфигурация GPT-6.1 Terra. Адаптация входного вызова и проверка выходного
поведения не равны универсальному восстановлению любых выходных схем.

## Данные и версии

| Опыт | Сценарии | Методы | Повторы | Решения |
|---|---:|---:|---:|---:|
| Phase 16, исходный | 2160 | 9 | 1 | 19440 |
| Phase 17, D0/D1 | 2160 | 2 | 1 | 4320 |
| Phase 18, два условия | 192 на условие | 5 | 3 | 5760 |
| Phase 20, Terra | Те же 192 на условие | 5 | 3 | 5760 слотов, 788 замен |

Условия Phase 18 сохраняются отдельно. Их нельзя объединять с исходным набором
в один средний показатель. Протокол зафиксирован в STUDY_PROTOCOL_1_4.md.
Готовые результаты находятся в `experiments/full-codeagent-2026-11-02/` и
`experiments/publication-2026-11-03/`. Оба условия завершены и проверены по полной матрице и хешам. Контроль B2V использует уже полученные кандидаты B2 и не добавляет
физических запросов к модели.

Версии исходного набора 1.0/1.1 сохранены для аудита, но выведены из основных
опытов. Базовый digest 1.2 и старые ответы не перезаписываются. Новый набор
compat-case-study-1.0 содержит другие прикладные обработчики и два отдельных
manifest с условиями доступности правил. Ссылки на точные исходники задаются
коммитами и source_digest, а не только изменяемым именем ветки.

## Словарь артефактов

- `manifest.json` набора: версия, seed, число сценариев, хеш каждого файла,
  общий digest. Каждый сценарий хранит контракты, старый вызов, метаданные и
  закрытый эталон; последние доступны оценщику после решения.
- `manifest.json` запуска: методы, параметры, версии модели/CLI, версии
  зависимостей, хеш исходных Python-модулей, fingerprint, время создания UTC.
- Файлы `повтор-метод-сценарий.json`: фактическое решение, кандидат, проверки,
  ответ и трасса генератора, измерения и доступные сведения использования.
- `result-digests.json`: хеш каждого сохранённого решения. Создаётся после
  полного завершения; отсутствие этого файла означает, что полный запуск
  ещё нельзя читать как завершённый анализатором.
- `summary.json`: сводка, вычисленная по решениям. Все доли имеют числитель и
  знаменатель; отсутствие знаменателя или неизвестное использование — null.
- `analysis.json`, CSV, SVG/PNG: производные показатели и кластерные интервалы.
  Указанные предпосылки статистики являются частью результата.
- `shared-core-proof.json`: совпадение общих модулей Phase 16 и D0/D1.
- `replay-phase16.json`: повторная проверка тех же кандидатов B2. Учёт их
  генерации наследуется из исходного B2, а не означает дополнительные запросы.

Известная нулевая стоимость в ответе провайдера не подтверждает полноту
внешнего биллинга. Ключи и содержимое пользовательских настроек не публикуются.
Сервисная ревизия, серверное оборудование и квантование CodeAgent не раскрыты.

## Воспроизведение проверок

Команды выполняются из корня репозитория под Python 3.11.4 с зависимостями из
requirements.lock. Окружение доступа к установленному клиенту настраивается
локально; секреты не передаются через командную строку или Git.

```sh
.venv/bin/python -m pytest -q --cov=mcp_compat --cov-branch --cov-report=term-missing --cov-fail-under=100
.venv/bin/ruff check src tests examples
.venv/bin/mypy src
UV_CACHE_DIR=/private/tmp/mcp-compat-uv-cache uv pip check --python .venv/bin/python
UV_CACHE_DIR=/private/tmp/mcp-compat-uv-cache .venv/bin/python -m build --installer uv
```

Полный локальный запуск по замороженным данным Phase 18 требует именно
экспериментального исходного кода `fda30006` (или его снимка из пакета).
Последующий патч D0 меняет глобальный source fingerprint; результаты не
переименовываются в измерение новой версии. Для клона Git можно использовать
отдельный checkout/worktree нужного коммита; в архиве приложен отдельный снимок.

Команда экспериментальной версии:

```sh
GIGACODE_BIN=/Users/dennrbone/.vscode/extensions/gigacode.gigacode-vscode-26.10.76/bin/gigacode .venv/bin/python examples/publication_case_study.py
```

Приведён фактический путь экспериментального Mac; на другой машине задаётся
локальный путь к той же версии установленного CLI. Скрипт проверяет версию CLI,
сохраняет конфигурацию, использует CodeAgent и продолжает только совместимый
запуск. Другой хеш исходников или параметры не позволяют тихо заменить опыт.
Повторное выполнение после завершения читает уже сохранённые решения; для
нового независимого измерения нужен отдельный каталог, а не удаление старых данных.

Проверка целостности завершённого условия:

```sh
.venv/bin/python examples/validate_publication_run.py --run experiments/publication-2026-11-03/case-study/runs/with-rules --benchmark experiments/publication-2026-11-03/case-study/data/with-rules --output /private/tmp/case-study-integrity.json
```

Проверка сверяет хеши, полную матрицу, метки, разрешённый вход мигратора,
независимую оценку исполнения и заново вычисленную сводку. Не запускается
с оптимизацией Python, отключающей assert. Проверяющий скрипт испытывается
на неполной матрице и правдоподобных, но неверных метках/входе.

Проверка тех же кандидатов без повторной генерации:

```sh
.venv/bin/python examples/replay_candidate_verification.py --run experiments/full-codeagent-2026-11-02/main --output /private/tmp/replay-phase16.json
```

Построение исходных таблиц с добавленными контролями:

```sh
MPLCONFIGDIR=/private/tmp/mcp-compat-matplotlib .venv/bin/mcp-compat-analyze --run experiments/full-codeagent-2026-11-02/main --additional-run experiments/publication-2026-11-03/declared-controls --output /private/tmp/declared-comparison --seed 42 --draws 2000
```

Анализ двух полностью завершённых условий, повторяемости и тех же кандидатов B2:

```sh
MPLCONFIGDIR=/private/tmp/mcp-compat-matplotlib .venv/bin/python examples/publication_results.py
```

Скрипт сначала проверяет полную матрицу и эталоны. Публикуются отдельные показатели
каждого повтора, распределение числа правильных повторов по уникальным сценариям
и причины ошибок попыток. Эти описательные показатели не увеличивают число
независимых инструментов и не заменяют основные CRR/UHR/FBR.

Русскоязычный рисунок рукописи строится из завершённого `analysis.json`:

```sh
MPLCONFIGDIR=/private/tmp/mcp-compat-matplotlib .venv/bin/python examples/publication_figures.py
```

Время B2V в производных метриках складывает сохранённое время генерации и
позднейшее время верификации. Это не новый измеренный сквозной запуск.

## Что необходимо подтвердить автору перед подачей

Организация пока не указана. Сведения о финансировании, конфликте интересов,
вкладе автора, применении программных ассистентов и иных декларациях должны
быть подтверждены автором в соответствии с правилами выбранной редакции.
Здесь не выдумываются ни организация, ни степень, ни внешняя рецензия.

Рукопись и результаты требуют авторской проверки. Не проведены внешнее
независимое воспроизведение, проверка несколькими семействами моделей и
применение на production-серверах. Технические тесты и литературное
сопоставление этого не заменяют. Выбор журнала, оформление по его шаблону,
отправка и принятие статьи не выполнены и не заявляются выполненными.

## Снимки исходников и локальный пакет

Архив `dist/mcp-compat-publication-2026-11-03.zip` содержит текущие код,
данные и материалы. В `experimental-source/` отдельно помещаются точные
снимки Phase 16 (`7fc2627e`), Phase 17 (`65d8c760`) и Phase 18 (`fda30006`).
Их суммарные хеши Python-модулей проверены на совпадение с manifest запусков.
Сопроводительный `PACKAGE_INFO.json` фиксирует Git-коммит пакета; рядом с ZIP
помещается SHA-256. Архив не содержит .git, окружения Python, локальных настроек,
ключей или мастер-задания с промптами. Это локальный пакет; доступ третьим лицам
автоматически не открывается.

Например, после распаковки из корня пакета для чтения/продолжения сохранённого
Phase 18 используется его код при тех же зависимостях:

```sh
PYTHONPATH=experimental-source/phase18-fda30006/src GIGACODE_BIN=/Users/dennrbone/.vscode/extensions/gigacode.gigacode-vscode-26.10.76/bin/gigacode .venv/bin/python experimental-source/phase18-fda30006/examples/publication_case_study.py
```

Это прочитает завершённые записи при совпадающем fingerprint. Для нового
измерения нужен отдельный каталог результатов; существующие frozen данные
не удаляются и не перезаписываются. Измерения нового сервиса не обязаны
повторить ответы непрозрачного alias; точный пересчёт сохранённых данных
и повторная генерация модельных ответов — разные виды воспроизводимости.

## Дополнение Terra

Результаты и адресная перезапись: TERRA_RESULTS.md и TERRA_COMPARISON.md.
В основной матрице заменены 788 наблюдений с последним ProviderError;
оригиналы и metadata находятся в before-provider-retry, полный исходный
Git-коммит db161df1. После пересчёта новый fingerprint содержит явную
provider_retry_policy; исходный runner не продолжает изменённую матрицу.
Завершённый retry проверяет хеши и не вызывает модель повторно.

Полный анализ: `.venv/bin/python examples/terra_results.py`. Он проверяет
обе модели, восстанавливает исходные оценки по старым хешам и публикует
исходную/пересчитанную таблицы. CodeAgent не имеет такого дополнительного
прохода; сравнение не даёт чистого причинного эффекта модели.
Температура/лимит вывода Terra не управляются CLI; учёт физических
обращений и стоимости неполон. Неизвестные значения остаются null.

Дополнительная реальная проверка Terra вызвала старый MCP-интерфейс через
proxy и получила минимум длины 2, число слов 3, стиль all; генерация
отображения и semantic_verified подтверждены сохранённой трассой.

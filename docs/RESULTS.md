## Общие знаменатели

Recoverable относится к существованию восстановления. Приемлемость конкретного
кандидата установлена отдельно по полным сохранённым evaluator-пробам C либо
невалидной входной схеме: 27 приемлемых и 36 неприемлемых. FAR считается среди
36 неприемлемых кандидатов; UHR — среди EXECUTE конкретного метода.

| Метод | TP | FP | FN | TN | FAR |
|---|---:|---:|---:|---:|---:|

| B | 27 | 0 | 0 | 36 | 0/36 |
| C | 27 | 33 | 0 | 3 | 33/36 |

| E | 0 | 0 | 27 | 36 | 0/36 |
| FULL | 27 | 0 | 0 | 36 | 0/36 |
| NO_FINAL | 27 | 3 | 0 | 33 | 3/36 |

Данные: `experiments/final-comparison-2026-11-05/analysis.json` и
`candidate-decisions.csv`. Старые определения метрик не менялись. Три неверных
enum-кандидата находятся в восстановимых сценариях; поэтому отказ на них
может увеличивать исторический FBR, оставаясь правильным решением о кандидате.

Для FAR B−A: Δ=−0,5833, 95% cluster bootstrap [−0,9167; −0,4167], p=0,25
при трёх источниках, p=0,5 при двух lineage. FULL−NO_FINAL: Δ=−0,0833,
вырожденный bootstrap-интервал, p=0,25/0,5. Источников мало, шаблоны общие,
iid/обменность не обеспечены случайным дизайном. Значимость и популяционная
гарантия безопасности **не установлены**. Нулевой UHR не означает нулевой риск.

## Подтверждённый объём реализации

Прямое сравнение наблюдений в evidence-3 устраняет дополнительное допущение
о digest для H/Q. Искусственно коллидирующий digest проверен отдельной
регрессией; реальная практическая коллизия SHA-256 не заявляется.
Консервативность относится к предоставленным декларациям профиля. Полнота
внешнего мира и атомарность remote commit автоматически не доказываются.

Основной gate: 379 PASS / 8 SKIP, 100% пакета по statements и branches;
отдельный SDK2/cross-SDK gate: 10 PASS. Статус установленного wheel,
целостности данных и документов — `validation/final-release.json`.
